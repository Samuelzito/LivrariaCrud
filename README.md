# 📚 LivrariaCrud

Este projeto é uma aplicação simples de cadastro de livros, desenvolvida em Java, com foco na prática de conceitos de Programação Orientada a Objetos (POO) e operações CRUD (Create, Read, Update, Delete).

## 🚀 Funcionalidades

- 📥 Cadastro de livros  
- 🔍 Consulta de livros cadastrados  
- ✏️ Atualização de informações  
- 🗑️ Exclusão de registros  
- 💾 Persistência em arquivo  

## 🛠️ Tecnologias utilizadas

- Java  
- Java Collections  
- Programação Orientada a Objetos (POO)  
- IDE: IntelliJ IDEA / Eclipse
